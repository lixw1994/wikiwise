## ADDED Requirements

### Requirement: Folder Icon Aspect Phase Tracking

The migration roadmap SHALL record Electron folder icon aspect parity as a native sidebar visual correction phase.

#### Scenario: Folder icon aspect phase is archived
- **WHEN** the Electron folder icon aspect parity change is archived
- **THEN** retained verification records native Swift `FolderIcon(size: 13)` frame and dot geometry evidence, Electron CSS folder-icon geometry coverage, preserved file-tree row behavior, package/build/runtime evidence, and release-readiness blocker evidence
- **AND** remaining final migration evidence still includes actual signed/notarized release execution or an explicitly accepted OpenSpec deviation
