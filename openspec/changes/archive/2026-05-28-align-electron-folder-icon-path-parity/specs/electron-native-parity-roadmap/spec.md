## ADDED Requirements

### Requirement: Folder Icon Path Phase Tracking

The migration roadmap SHALL record Electron folder icon path parity as a native sidebar visual correction phase.

#### Scenario: Folder icon path phase is archived
- **WHEN** the Electron folder icon path parity change is archived
- **THEN** retained verification records native Swift `FolderIcon` path evidence, Electron SVG path coverage, preserved file-tree row behavior, package/build/runtime evidence, and release-readiness blocker evidence
- **AND** remaining final migration evidence still includes actual signed/notarized release execution or an explicitly accepted OpenSpec deviation
