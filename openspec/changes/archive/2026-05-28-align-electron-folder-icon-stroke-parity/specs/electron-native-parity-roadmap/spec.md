## ADDED Requirements

### Requirement: Folder Icon Stroke Phase Tracking

The migration roadmap SHALL record Electron folder icon stroke parity as a native sidebar visual correction phase.

#### Scenario: Folder icon stroke phase is archived
- **WHEN** the Electron folder icon stroke parity change is archived
- **THEN** retained verification records native Swift `FolderIcon(size: 13)` stroke-width evidence, Electron CSS folder-icon stroke coverage, preserved file-tree row behavior, package/build/runtime evidence, and release-readiness blocker evidence
- **AND** remaining final migration evidence still includes actual signed/notarized release execution or an explicitly accepted OpenSpec deviation
