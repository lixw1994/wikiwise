## Why

The Electron app currently proves only a static shell and resource metadata bridge. To move toward native parity, it needs the same first user journey as the SwiftUI app: show a welcome screen, let the user open an existing folder or file, scan the project tree, and select files.

## What Changes

- Add reusable core helpers for scanning Wikiwise-visible files and reading text files.
- Add Electron main-process IPC handlers for opening a folder/file picker, scanning a project, and reading file contents.
- Expand the preload bridge with project lifecycle APIs.
- Replace the static renderer placeholder with a minimal app state that can show a welcome screen, file tree, selected file content, and shared resource metadata.
- Keep Create New Wiki, compiler, live preview, editor saving, terminal, publishing, and watcher parity for later phases.

## Success Criteria

- Core tests verify the Electron file tree matches native filtering and ordering rules.
- Electron tests verify project lifecycle IPC/preload/renderer files exist without launching Electron.
- `npm test` passes.
- OpenSpec strict validation passes.
- Retained verification records which native lifecycle behaviors are implemented and which are deferred.

## Non-Goals

- No wiki compilation or preview parity in this phase.
- No CodeMirror editor saving.
- No scaffold creation for new wiki.
- No terminal, publishing, file watcher, map, or native menu parity.
- No final packaging/release work.

## Capabilities

### New Capabilities

- `electron-project-lifecycle`: Opening existing folders/files, scanning the project tree, and selecting files in the Electron app.

### Modified Capabilities

- `wikiwise-core-package`: Add file tree scanning and text file reading helpers for Electron.
- `cross-platform-electron-workspace`: Extend the Electron shell from static resource display to project lifecycle IPC and renderer state.

## Impact

- Modifies `packages/wikiwise-core`.
- Modifies `apps/electron` main, preload, renderer, CSS, and tests.
- Adds/updates npm lockfile generated by Electron dependency installation.
- Does not modify Swift source or native release scripts.
